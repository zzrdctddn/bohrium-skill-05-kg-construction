# 文献知识图谱自检清单（逐项打钩）

## 抽得准（机制 E）
- [ ] 实体均为论文真实出现的对象，未凭常识补概念
- [ ] 每个实体保留原文表述与 source_id + JATS paragraph_id + 原文短引
- [ ] 区分作者自述/他人转述
- [ ] 无证据的实体标 unverified 并进 uncertainties
- [ ] 位置为 JATS 段落 ID，未自建 PDF 页码

## 连得对（机制 C）
- [ ] 每条边有原文证据，关系类型来自受控词表
- [ ] 关系方向、适用条件与原文一致
- [ ] 未把共现/综述转述/推测当直接证据
- [ ] 主体未张冠李戴

## 对得齐（机制 G）
- [ ] 别名/缩写/大小写/全称简称/同名冲突逐对给出合并或不合并依据
- [ ] 未强迫每个别名都合并
- [ ] 未把不同论文的条件/样本/数值合成一个结论
- [ ] 相同通用术语未推断为相同样品/模型/数据集/条件
- [ ] merge_decisions 与 conflicts 全部留痕

## 查得到、回得去（机制 CQ）
- [ ] 每个节点和边都能回到 source_id + paragraph_id + 原文短引
- [ ] 至少 3 个实际执行的查询，附结果子图与支撑证据
- [ ] 无结果/不确定关系如实列出，未编造
- [ ] 证据强度已标注（strong/weak）

## 结构与边界
- [ ] 两篇论文按独立来源登记，根 DOI/作者未互套
- [ ] 同篇多格式未被当跨篇证据
- [ ] status 诚实（success/partial/blocked）
- [ ] 材料缺失/无法判断/运行失败分别说明
- [ ] 未编造数据、来源与 benchmark 分数
- [ ] 抽取与核验分离完成，所有改动有 change_log
